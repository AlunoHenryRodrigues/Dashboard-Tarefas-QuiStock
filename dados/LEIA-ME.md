Coloque a planilha do projeto com o nome `QuiStock.xlsx` nesta pasta.

O dashboard lê as duas turmas automaticamente. Quem abre o site não precisa importar nem configurar colunas. A planilha também pode ficar na raiz do projeto, ao lado de package.json.

O arquivo Excel é ignorado pelo Git. Nenhuma cópia institucional acompanha o código no GitHub. Durante a publicação, o build gera os dados calculados a partir desta cópia local.
